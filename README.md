# Reelio AI

Мобильное приложение — AI‑редактор вертикальных роликов (Reels) для iOS и Android.
Пользователь выбирает видео и фото из галереи, описывает идею ролика, настраивает
стиль, субтитры и музыку, а приложение **имитирует** автоматический AI‑монтаж и
готовит вертикальный ролик 9:16.

> ⚠️ Это интерактивный MVP. Настоящего AI‑бэкенда и видеорендеринга пока нет —
> монтаж и экспорт реализованы мок‑логикой. Архитектура подготовлена так, чтобы
> позднее подключить серверный API без переписывания UI.

## Технологии

- **Flutter** 3.44+ / **Dart** 3.12+ (собрано и проверено на Flutter 3.44.8)
- **Material 3**, светлая и тёмная темы
- **Riverpod** (`flutter_riverpod`) — управление состоянием
- **GoRouter** — навигация
- `image_picker`, `video_player` — выбор и просмотр медиа
- `shared_preferences` — локальное хранение черновика
- `share_plus`, `path_provider` — экспорт монтажного плана

Требуется установленный Android SDK (Android Studio).

### Ключевые абстракции (готовы к замене на реальный бэкенд)

```dart
abstract class AiEditingService {
  Future<EditPlan> createEditPlan(EditRequest request);
}

abstract class VideoExportService {
  Future<ExportResult> export(EditPlan plan);
}
```

Сейчас работают `MockAiEditingService` и `MockVideoExportService`. UI зависит только
от абстракций через провайдеры (`aiServiceProvider`, `exportServiceProvider`), поэтому
подключение HTTP‑клиента — это замена реализации в одном месте.

## Ограничения продукта (жёстко зашиты в `core/constants.dart`)

- до 20 видео и до 20 фотографий;
- одно видео — не более 10 минут (проверяется по фактической длительности);
- итоговый ролик — не более 120 секунд;
- видео: MP4, MOV; изображения: JPG, JPEG, PNG, HEIC, WebP;
- все сообщения и ошибки — на русском языке.

## Локальное хранение

Черновик (материалы, настройки, монтажный план, текущий этап, правки) сохраняется в
`shared_preferences`. После перезапуска стартовый экран предлагает «Продолжить черновик».
Есть полное удаление проекта с подтверждением (кнопка «Создать ролик» → диалог).

## Что реализовано

- Полный сквозной сценарий из 7 экранов с индикатором этапов и обработкой системной «Назад».
- Премиальный Material 3 UI: холодный фон, глубокий фиолетовый, лавандовые поверхности,
  лаймовый акцент, крупные скругления, мягкие тени, градиенты, светлая/тёмная тема,
  безопасные отступы, touch‑цели ≥44×44, ограниченный Dynamic Type, плавные анимации.
- Выбор видео/фото из галереи с проверкой количества, формата и длительности,
  счётчиками, превью, изменением порядка, удалением и полноэкранным просмотром.
- Настройки: промт с подсказками, стиль, длительность, субтитры (язык), музыка и громкость.
- Мок‑обработка 8–12 с с анимацией, этапами и процентом; авто‑переход в предпросмотр.
- Предпросмотр 9:16 с демо‑плеером, таймшкалой, субтитрами и данными о ролике.
- Правки: таймлайн, порядок/удаление клипов с отменой, субтитры (текст/стиль/цвет),
  музыка/громкость, выбор обложки, сохранение.
- Экспорт: параметры 9:16 / 1080p, демо‑оценка размера, сохранение монтажного плана (JSON)
  во временный каталог и системное меню «Поделиться» с явной пометкой демо‑экспорта.

## Что остаётся подключить для настоящего AI‑монтажа

1. Реальный `AiEditingService` — HTTP‑клиент к серверу, возвращающий `EditPlan`
   (загрузка/анализ материалов, выбор моментов, субтитры, музыка). Мок можно снять,
   не трогая UI.
2. Реальный `VideoExportService` — серверный рендеринг MP4 (FFmpeg/облако), возврат
   ссылки на готовый файл вместо JSON‑плана.
3. Загрузка исходников в объектное хранилище по подписанным URL (сейчас файлы **не**
   отправляются в сеть).
4. Настоящий плеер результата вместо демо‑поверхности предпросмотра.
5. Speech‑to‑text для реальных субтитров и каталог лицензированной музыки с ducking.
