# reelio-ffmpeg-worker-v2

Исполнитель рендера для [контракта v2](../../docs/render-contract-v2.md).
Отдельный деплой: production `backend/worker` (v1) не заменяется и продолжает
работать со своим контрактом.

```
plan.json (v1 или v2) ──► [ffprobe] ──► filter_complex ──► libx264 (+AAC) ──► MP4
                                │                                    │
                                └──── POST /internal/jobs/{id}/progress ◄──┘
```

## Что изменилось относительно v1

| Область | v1 | v2 |
|---|---|---|
| Музыка | подложка + ducking | **удалена целиком** |
| Звук | микс речи и музыки | переключатель `audio.keepOriginal` |
| Переходы | 4 значения строкой | каталог из 21 типа с длительностью и интенсивностью |
| Текст | только `sampleText` в субтитрах | модель `TextOverlay` с нормализованными координатами |
| Шрифты | DejaVu из образа | каталог §5, те же файлы, что у web-превью |
| Субтитры | 3 стиля | 4 стиля, реплики из распознавания, выделение слов |
| Экспорт | разрешение | плюс пресет `instagramReels` |

## Звук (§1)

Фоновой музыки в продукте больше нет: пользователь добавляет трендовый трек
уже внутри Instagram, поверх готового ролика. Worker никогда не загружает, не
синтезирует и не подмешивает музыку.

**`audio.keepOriginal: true`** — оригинальный звук сохраняется: дорожки клипов
склеиваются в порядке монтажа, на «сухих» стыках ставится микрофейд 15 мс
(он и убирает щелчок), на плавных переходах работает `acrossfade`, громкость
нормализуется до −16 LUFS, мастер защищён лимитером.

**`audio.keepOriginal: false`** — в MP4 нет аудиопотока вовсе.

Клипы без звука (фото, немые видео) занимают свой отрезок тишиной. Это
выравнивание таймлайна, а не искусственная дорожка: без него звук последующих
клипов уехал бы относительно картинки. Если звука нет **нигде**, аудиопоток не
создаётся совсем.

Субтитры от переключателя не зависят: текст уже распознан и лежит в плане.

## Переходы (§2)

Сторонние transition pack'и не используются — только то, что умеет сама сборка
FFmpeg. При запуске worker спрашивает `ffmpeg -h filter=xfade` и строит
**проверенный каталог**: пересечение таблицы контракта с возможностями бинаря.
UI получает его же, поэтому выбрать нерендерящийся переход нельзя. Тип вне
каталога откатывается на растворение и попадает в `notes`, а не роняет рендер.

Длительность — 0.15…1.5 с, либо из интенсивности (`calm` 0.8, `balanced` 0.45,
`dynamic` 0.25). Перекрытие не длиннее 40% более короткого соседа; если после
ограничения остаётся меньше 0.15 с, переход честно вырождается в стык.

## Текст (§4)

Координаты нормализованы: в плане только доли кадра, умножение на реальный
размер происходит в одном месте. Поэтому один план даёт одинаковую раскладку в
720p, 1080p, 2K и 4K — это покрыто тестом, который сверяет измеренные доли во
всех четырёх разрешениях.

Безопасная зона Instagram (сверху 14%, снизу 20%, по бокам 6%) проверяется для
каждого слоя. Текст за её пределами **сдвигается внутрь** с пометкой в `notes`:
испорченный экспорт хуже подписи, сдвинутой на пару процентов.

**Пользовательский текст никогда не попадает в `filter_complex`.** Он пишется в
UTF-8 файл `.ass`, а FFmpeg получает только путь к файлу. Это снимает целый
класс инъекций через `:`, `'`, `,`, `\` и `[]`.

## Шрифты (§5)

Девять семейств с кириллицей из `assets/fonts/` — те же файлы, что использует
web-превью, поэтому экспорт совпадает с экраном. Обновляются скриптом
`node tools/fetch-fonts.mjs` (статические начертания из Google Fonts CSS API,
лицензии кладутся рядом). Неизвестный `fontId` не ошибка: берётся `inter`.

## Запуск

Переменные окружения — как в v1 (§9), плюс:

| Переменная | По умолчанию | Значение |
|---|---|---|
| `REELIO_CONTRACT_VERSION` | `2` | Версия контракта |
| `REELIO_FONTS_DIR` | `/opt/reelio/fonts` | Каталог шрифтов §5 |

`REELIO_MUSIC_DIR` и `REELIO_FONT_NAME` из v1 больше не используются.

## Тесты

```bash
npm test           # всё
npm run test:unit  # без FFmpeg
npm run test:e2e   # нужен ffmpeg + ffprobe
```

E2E работают в local mode: хранилище — временный каталог, канал §8.1 —
HTTP-сервер на `127.0.0.1`. Ни облачных ресурсов, ни обращений наружу.

Что проверяется по-настоящему:

* **оба режима звука** — MP4 с оригинальной речью и MP4 совсем без аудиодорожки
  (проверяется отсутствие потока в контейнере, а не только флаг);
* **каждый переход каталога** рендерится на синтетических клипах, и длительность
  результата совпадает с расчётом таймлайна;
* сборка во всех четырёх разрешениях §1 с текстовым слоем;
* совпадение позиции и кегля текста в 720p, 1080p, 2K и 4K;
* русский текст со спецсимволами и попытки инъекции команд ASS;
* план v1 рендерится worker'ом v2 без изменений;
* синхронность видео и звука после склейки;
* faststart разбором боксов `moov`/`mdat`;
* отмена с уборкой tmp, повреждённый исходник, нормализация поворота;
* запуск из дерева образа — гарантия, что COPY полон.

`contract-sync` парсит оба документа контракта и сверяет с ними таблицы
разрешений, фаз, переходов, шрифтов, безопасной зоны и параметров звука.

## Образ

Контекст сборки — **корень репозитория**: образу нужны шрифты.

```bash
docker build -f backend/worker-v2/Dockerfile -t reelio-ffmpeg-worker-v2 .
```

Зависимостей npm нет: обращения к Cloud Storage сделаны на `fetch` поверх JSON
API, аутентификация — ADC/Workload Identity. Минимальная версия FFmpeg — 5.1.
